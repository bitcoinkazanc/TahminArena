# TahminArena

Telegram Mini App tabanlı sosyal futbol tahmin platformu.

## Teknolojiler

- Next.js
- TypeScript
- React
- Supabase
- Vercel
- Telegram Mini Apps
- Mackolik maç verileri
- Cron-job.org

## Temel Özellikler

- Futbol maçları
- Kullanıcı tahminleri
- Tahmin paylaşımı
- Kupon oluşturma
- Genel sohbet
- Maç özel sohbeti
- Kullanıcı profilleri
- Takip sistemi
- Beğeni / beğenmeme
- Yorumlar
- Bildirimler
- Liderlik tablosu
- Engelleme
- Raporlama
- Moderasyon

## Veri Kaynağı

Mackolik yalnızca futbol maç verileri için kullanılacaktır.

İddaa oranları TahminArena sisteminde kullanılmayacaktır.

## Platform

TahminArena, Telegram Mini App olarak çalışacak şekilde tasarlanmıştır.

## Geliştirme

Proje Next.js ve TypeScript ile geliştirilmektedir.

Veritabanı Supabase üzerinde tutulacaktır.

Uygulama Vercel üzerinde yayınlanacaktır.

Periyodik veri güncellemeleri Cron-job.org üzerinden gerçekleştirilecektir.
